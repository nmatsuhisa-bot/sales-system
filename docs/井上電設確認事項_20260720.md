# 第1部　図面の定義に関する確認事項

## CAD-1. 外部参照の取り込みと「自社が描いた範囲」の判別 【新規・優先度高】

釧路製材棟（280001A）は**レイヤーが90個**あり、他図面（11〜22個）と桁が違います。
内訳を見ると、明らかに**他社図面が外部参照(XREF)で取り込まれて**います。

| 実際のレイヤー名 | 推定される出所 |
|---|---|
| `Muotoviivat` `Katkoviivat` `Yhtenäinen` `Mitat` | フィンランド語。海外製機械メーカーの図面 |
| `Hoone-AM_0` | エストニア語（hoone＝建屋） |
| `CONVEYOR` `CONVEYORS_RESIDUE` `DRIVE` `EXT_EQUIPMENT` | 搬送機メーカーの図面 |
| `0_外部参照` `EXTERNAL` | 外部参照であることの明示 |
| `製材工場棟$0$ITTEN-1` | 外部参照をバインドした痕跡（`$0$` は AutoCAD の XREF バインド記法） |

**ご確認いただきたいこと**

1. この図面で**井上電設様が作図された範囲はどのレイヤーか**
2. 今後、外部参照で取り込んだ他社図面と自社作図分を、**レイヤー名の接頭辞で機械的に判別できる運用**にできるか
   （作図標準ドラフト2章の `INOUE_*` / `背景_*` がこれに当たります）

> 見積は「自社が供給する範囲」だけを対象にするため、この判別ができないと
> 他社機器を見積に混入させてしまいます。

## CAD-2. ダクト継手の作図が図面ごとに統一されていない 【優先度高】

継手（フランジ・エルボ・径違い受け）のブロック配置数を全図面で数えました。

| 図面 | フランジ | エルボ | 受け／角ダクト | 既設明示 |
|---|---|---|---|---|
| 川井林業 | **97** | 2 | 6 | 4 |
| 釧路 製材棟 | **35** | 0 | 12 | 0 |
| 本多木工所 | 3 | 0 | 0 | 0 |
| 釧路 加工棟 | 3 | 0 | 0 | 0 |
| 西北プライウッド | 0 | 5 | 0 | 0 |
| 新栄合板 | **0** | **0** | 0 | 0 |

どの案件も集塵ダクトを施工されているはずですが、**継手をブロックで描くかどうかが
図面ごとに全く異なり**、新栄合板に至っては継手ブロックが1つもありません
（＝線で直接描かれている）。

**ご確認いただきたいこと**

1. 継手をブロックで配置するか線で描くかは、**作図者ごとの流儀か、案件の性質によるものか**
2. 継手を**ブロック配置に統一**できるか。統一できれば継手は自動で数量が拾えます

## CAD-3. フランジのブロック名は「そのまま積算に使える」情報を持っている 【朗報・要確認】

フランジのブロック名には、**径・アングル材・板厚まで**入っていました。

```
単色ダクトフランジφ555-L5×40正面     → φ555 / アングル L5×40
単色ダクトフランジφ379.5-4.5ｔ正面   → φ379.5 / 板厚 4.5t
単色ダクトフランジφ454-L3×25正面     → φ454 / アングル L3×25
```

これは**部品表がそのまま作れる粒度**です。継手さえ統一して配置いただければ、
ダクト部品の積算精度が大きく上がります。

**ご確認いただきたいこと**

1. `L5×40` `L3×25` `L3×30` は**アングル材のサイズ**、`4.5ｔ` は**板厚**という理解で正しいか
2. 径の表記が `φ555`（フランジ外径）と、注記の `φ500`（ダクト内径）で
   **基準が違う**ように見えます。フランジ径からダクト呼び径を求める規則はあるか
3. 接頭辞の **`単色`** は何を意味するか（全図面・全フランジに付いています）

## CAD-4. エルボに径の情報が無い

エルボは全図面で **`ｴﾙﾎﾞ` / `ｴﾙﾎﾞ下り新`** という2種類の名前だけで、
径が分かりません（フランジと対照的です）。

**ご確認いただきたいこと**
- エルボのブロック名に**径と曲がり角度**を持たせられるか（例: `ｴﾙﾎﾞ_φ500_90度`）
- `下り新` の「新」は何を指すか（新規／新形状／改訂版？）

## CAD-5. 角ダクトの扱い

川井林業に `550_角ﾀﾞｸﾄ` `700_角ﾀﾞｸﾄ` があります。
現在のダクト概算式は**丸ダクト（φ×単価）前提**のため、角ダクトに適用できません。

**ご確認いただきたいこと**
- 角ダクトの積算単位（周長か・断面積か・㎡単価か）
- `550` `700` は一辺の寸法か、それとも相当径か

## CAD-6. 径違い（レデューサ）の表記

釧路製材棟のみ `ﾀﾞｸﾄ受け_600-475_正面` `ﾀﾞｸﾄ受け_200-375_正面` という
**径違い継手が読み取れる形**で入っていました。これは理想的な命名です。

**ご確認いただきたいこと**
- この `ﾀﾞｸﾄ受け_大-小` の命名を**全図面の標準**にできるか
- `ﾀﾞｸﾄ受け_650_正面`（径が1つだけ）は同径の受けか、別の部品か

## CAD-7. 既設・支給品の明示

`既設ｵｶﾞﾔｰﾄﾞ` `既設ｺﾝﾍﾞﾔ` `既設ｻｲｸﾛﾝ_平面` `既設ﾌｧﾝ_平面` という

**ご確認いただきたいこと**

## CAD-9. ダクトの系統別レイヤー分離の受け入れ可否 【最重要・前版D-6の継続】

前版からの継続確認です。**このルールが無い限りダクト長の自動積算は原理的に不可能**
であることは、6図面すべてで検証済みです。

一方で今回、**線種 `CENTER` / `CENTER2` は全6図面に存在**することが分かりました。
実測検証の結果、**作図方法は現状のままでもレイヤーを分けるだけ**で実現できる見込みです。

**ご確認いただきたいこと（後藤様・柴田様）**
- ダクトを**系統ごとに別レイヤー**（`INOUE_ダクト_集塵` 等）へ分ける運用が
  実務上受け入れ可能か
- 立ち上がりの `(6000H)` 形式の高さ注記を必須にできるか
  （西北プライウッドに `φ300SD(6000H)` の実例あり）

## CAD-10. ダクト概算係数の妥当性 【前版D-8の継続】

作図標準が入るまでの暫定式です。**係数は当方の仮置き**です。

```
概算金額 = Σ 径ごと（ 径(mm) × 20円 × 想定延長 ）,  想定延長 = φ注記の件数 × 6m
```

| 案件 | 御見積のダクト部品 | 当方の概算 | 差 |
|---|---|---|---|
| 新栄合板 | 550,000 | 467,000 | −15% |
| 西北プライウッド | 500,000 | 623,000 | +25% |

- `20円/(mm・m)` と `1件あたり6m` は実務感覚と合うか
