# 工場機械・図面管理 要件整理と実装方針（2026-09-15）

販売管理システム（sales-system）内の独立モジュール `/equipment`。既存テーブルは変更しない（`eq_*` テーブルを追加）。

## 1. 目的

1. 工場の機械を **管理ID** で一元管理する（機械一覧表 PDF の管理番号をそのまま管理IDにする）
2. **固定資産台帳**（会計ソフトの CSV、機械以外の資産も含む）と機械を紐付け、期ごとの取込で差分を追う
3. 機械一覧にあって台帳に無いもの／台帳にあって機械一覧に無いものを **突合** して整理できる
4. **配置図**の上に機械を置き、ドラッグで移動。移動は下書きとして 1 件ずつ保存し、図面単位の **確定** で反映。過去時点の配置を再現できる

## 2. 入力データと分かったこと（2026-09-15 時点の実データ）

| データ | 実体 | 件数 |
|---|---|---|
| 機械一覧表 | `20260616_工場機械一覧表.pdf`（7 ページ、表形式） | 289 行 → 機械 273 台（同一番号の付帯行 7、番号なし 9） |
| 固定資産台帳 | `2026年02月〜2027年02月期 固定資産台帳CSV.csv`（Shift_JIS・41 列） | 247 行（機械装置 74 / 工具器具備品 41 / 一括償却 18 / リース 2 / 建物・附属設備・車両など 112） |
| 配置図 | `20260625_工場図面/*.pdf` 10 枚（井上電設作成、A3、ラスタ画像） | 桜田(全体・製缶・切削・組立・板金)、小牧、沢下1F/2F、福江、第3倉庫 |

- 管理番号の体系は `S1-`,`S2-`,`SK-`,`SKW-`,`SW-`,`SA-`,`SR-`,`F-`,`FW-`,`FA-`,`B-`,`BW-`,`K-`,`KW-`,`KA-`,`H-`,`施-` の 17 種＋枝番 `a`。頭字は **導入当時の工場** で現在の所在とは一致しない（F-02 ｷｰ溝機は沢下にある）。→ 番号は変えず、所在は配置で表す。
- 台帳の資産名先頭は **工場プレフィックス付き**（`SKF-07`=桜田+F-07、`KK-14`=小牧+K-14、`F-B3`=福江+B-03、`HH-09`、`SH-03`、`D3B-26`=第3倉庫+B-26）。2019 年以降はプレフィックス無し。
- 台帳の管理番号は 10 桁連番。空欄が 30 件（一括償却資産など）。除却日は全件空欄（除却済みは行ごと消える前提）。
- 配置図は **赤枠で機械番号が焼き込まれている**。システム上で動かしても図面の番号は残るため、赤色成分を画像処理で消した画像を背景にし、番号入りの元図面は「元図面」表示で参照する。

## 3. データ構造（`eq_*`）

```
eq_sites           拠点（桜田北・桜田南・小牧・沢下・福江・第3倉庫・本社・第2倉庫 を初期投入）
eq_drawings        図面（拠点, 名称, 背景画像 bytea, 元図面 bytea, 幅高px, 縮尺メモ, 図面の日付, 有効/無効）
eq_machines        機械マスタ（code=管理ID, 一覧表の全列, price, status[active/removed/disposed/unknown], extra_rows=付帯行）
eq_assets          固定資産台帳スナップショット（period, asset_key, 台帳の主要列, raw=全列 JSON） UNIQUE(period, asset_key)
eq_machine_assets  紐付け（machine_id, asset_key, link_type[本体/付帯工事/移設費/親資産に含む/リース/その他], confidence[confirmed/candidate], note）
eq_commits         確定（図面, 日時, 操作者, メモ, 操作数）
eq_placements      配置（machine, drawing, x, y[0〜1 の比率], valid_from, valid_to=NULL が現在, commit_id）
eq_moves           移動 1 件ごと（図面, 機械, seq, kind[place/move/remove], from/to 座標, 日時, 操作者, commit_id=NULL が下書き, undone_at）
```

- `asset_key`: 台帳の管理番号。空欄の資産は `'N' + sha1(資産名|取得日|取得価額)[:10]`（同一キーは `-2`, `-3`）。期をまたいで同じ資産を同じキーで追える。
- 紐付けは **多対多**（台帳 1 行＝機械 3 行: SK-17 本体＋電気工事 2 件、機械 1 行＝台帳 2 行: F-14 本体＋制御盤の枝番）。
- **時点復元**: `eq_placements` を有効期間で持つ。`as_of` 指定時は `valid_from <= as_of < valid_to` で引く（日付だけ指定ならその日の終わり）。
- **下書き→確定**: ドラッグ 1 回 = `eq_moves` 1 行（commit_id NULL）。「1つ戻す」は `undone_at` を入れる（行は残す）。「確定」で機械ごとの最終状態だけを配置に反映し、下書き（取り消し済みを含む）を確定に紐づける。動かして元の位置に戻した機械は履歴を切らない。
- 機械は 1 か所にしか無い: 別図面で `place` して確定すると、他図面の現在の配置は自動で閉じる。

## 5. 画面（`/equipment`、サイドバー「工場機械管理」。管理者のみ表示・アクセス可）

1. **図面（配置）**: 図面選択・時点（日付）・元図面表示・拡大縮小。チップをドラッグで移動、右の「未配置の機械」から図面へドロップで配置、選択して「図面から外す」。上部バーに未確定件数・1つ戻す・すべて破棄・確定。「確定履歴」から任意の確定時点の配置を表示。チップをダブルクリックで機械の履歴。
2. **機械一覧**: 一覧表の列＋現在の図面・台帳紐付け・状態。編集モーダルで属性と紐付け（追加・確定・削除）。
3. **固定資産台帳・突合**: 期の選択。突合サマリ（「有」なのに未紐付け／要確認／台帳側で未紐付け／機械側で未紐付け）と台帳一覧（機械へ紐付け）。
4. **取込・設定**: テーブル作成、機械一覧表 CSV、台帳 CSV（前期との差分表示）、自動紐付け・紐付け CSV、図面登録・一覧、拠点追加。

## 6. 導入手順（本番）

1. push → Render 自動デプロイ
2. 管理者でログイン → 「工場機械管理 → 取込・設定 → テーブル作成（初回）」
3. ローカルで CSV・画像を作る
   ```
   python3 tools/equipment_machine_list_pdf2csv.py ~/Downloads/20260616_工場機械一覧表.pdf -o _work/equipment/machine_list.csv
   python3 tools/equipment_prepare_drawings.py ~/Downloads/20260625_工場図面 -o _work/equipment/drawings
   python3 tools/equipment_initial_links.py "<台帳.csv>" _work/equipment/machine_list.csv -o _work/equipment/links_initial.csv
   ```
   （pdfplumber / PyMuPDF / Pillow / numpy が必要。`_work/` はコミットしない）
4. 画面で ②機械一覧表 → ③台帳 → ④自動紐付け → ④紐付け CSV → ⑤図面（背景＝`<名前>.png`、元図面＝`<名前>_original.png`）の順に取込
5. 図面タブで「元図面」を表示しながら未配置の機械をドロップして初期配置 → 確定
6. 「固定資産台帳・突合」タブで要確認の紐付けを確定／削除

## 8. 決めたこと・残課題

- 管理IDは既存番号のまま（ユーザー確認済み 2026-09-15）。図面背景は赤色除去した画像（同）。組込み先は sales-system-v2（同）。
- 一覧表の「機械移設工事」行（桜田・番号なし・5 件）は機械ではないため取り込まない。台帳側の「機械移設工事」5 件も紐付け対象外（必要なら機械側に移設費として手動紐付け）。
- 機械番号の OCR は行わない（tesseract 無し）。初期配置は元図面を見ながら手作業。
- 図面が更新された場合は「画像差し替え」（同じ縦横比なら配置はそのまま）。縦横比が変わる場合は新しい図面として登録し、機械を移設する。
- 残: 機械ごとの点検・修理記録の構造化（現状は一覧表の自由記述をそのまま保持）。
